# MOHD ARSH // DIGITAL LAB

An editorial, framework-free personal portfolio for Mohd Arsh — a 3rd-year B.Tech CSE student at DIT University, Dehradun, full-stack developer in progress, DevOps learner and creative technologist.

## Run locally

```bash
npm start
```

Open [http://localhost:4173](http://localhost:4173) in your browser. You can also run `node server.js` directly if you do not want to use npm.

## Personalize it

1. Replace the placeholder GitHub, LinkedIn and Instagram URLs in `index.html`.
2. Update `arshhk5775@gmail.com` in the contact links and `script.js` if your contact email changes.
3. Add an audio file you own or have permission to use at `assets/audio/track.mp3`. The player falls back to a visual-only mode until this file exists.
4. Replace the three honest project slots in the `001 / SELECTED WORK` section with real projects when you are ready. Each slot is intentionally empty so the portfolio does not invent work for you.

## Included

- Responsive layout for phone, tablet and desktop
- Warm editorial/brutalist visual system with oversized type, thin rules, orange/red accents, asymmetry and technical labels
- Custom cursor on fine-pointer devices
- Scroll reveal animations and active navigation state
- Animated stats, responsive mobile menu and hover states
- Functional audio player with volume, progress and fallback visual mode
- Contact form that opens a pre-filled email draft, plus copy-email action

No external framework or build step is required.
